# Proposal: Add Idempotency Keys & Signed Webhook Events

Добавить защиту от дублирующих запросов создания заказа (`Idempotency-Key` с проверкой совпадения payload) и генератор подписанных HMAC-SHA256 webhook-событий для внешних интеграций.
Цель: исключить двойные списания при сетевых ретраях и обеспечить верификацию подлинности webhook-уведомлений.
